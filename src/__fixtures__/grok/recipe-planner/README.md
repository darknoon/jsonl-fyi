# Synthetic Grok Build session

Every message, path, identifier, timestamp, command, and pixel here was invented for tests. No content was copied from a real session. The illustration is a 480×320 PNG generated from colored pixels.

`chat_history.jsonl` covers all six specialized tools, two generic tools, results arriving out of call order, blank assistant records, a terminal failure, and text-plus-image and image-only results. `updates.jsonl` and `events.jsonl` are synthetic companion streams for wrong-file guidance; they are not supported transcripts.
