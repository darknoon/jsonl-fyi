# Contributing

Thanks for using jsonl.fyi. A quick note on what's open and what isn't:

## Bug reports — yes, please

Open an [issue](https://github.com/darknoon/jsonl-fyi/issues) and **attach the `.jsonl` file** that triggered the bug (or a minimal slice of it). Without the actual transcript I usually can't reproduce — the bugs are almost always shape-of-data bugs.

If the file contains anything sensitive, redact it locally first or email me instead.

## Enhancement ideas — discuss first

Use [GitHub Discussions](https://github.com/darknoon/jsonl-fyi/discussions) to propose features or changes before doing any work. I'd rather talk through the idea than receive a surprise PR.

## Pull requests — not currently accepted

This is a personal project and I'm not set up to review outside PRs. If you've got an idea you'd like to see, file a discussion (above) and I may pick it up myself.

Forks are obviously fine — the license permits it.
